Sergi tiene suscripción tarifa plana en nan.builders que le da acceso a API de LLMs. Ya la usa para otros proyectos. Usar esta vía para cualquier automatización que necesite llamadas a LLM en lugar de pagar tokens directamente a Anthropic/OpenAI.
