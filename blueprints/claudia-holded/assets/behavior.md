# Personalización — claudia-holded

Este fichero permite ajustar el comportamiento de la skill para tu instancia,
sin tocar el código compartido. Déjalo vacío si no necesitas ajustes.

Ejemplos de ajustes que podrías anotar aquí:
- Proveedores que SÍ autorizas a crear como contacto automáticamente.
- Excepciones de IVA por proveedor que difieren del histórico.
- Preferencias de redacción de las notificaciones.
